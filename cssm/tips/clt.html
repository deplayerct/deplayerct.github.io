# Corn 贡献许可条款（Contributor License Terms，CLT）

说明：本条款旨在界定“向 Corn 提交代码／文档的贡献者”与 Deplayer Creator Team（即本项目版权署名的 DeplayerCT，以下简称 DCT）之间与贡献相关的权利义务。我们很不乐意谈论这一问题，但为确保协作顺畅，仍需明确如下：

在提交 Pull Request 或 Git commit 之前，请您务必阅读以下条款。
提交即视为您已接受本条款的全部内容。

0. 原版 Corn 项目为由 Deplayer Creator Team（DCT）在项目 README 或官方文档中明确指定为 Corn 官方上游仓库（official upstream repository）的代码仓库，以及 DCT 以书面或公开声明方式指定的其直接延续仓库。DCT 会在 README 中维护该官方仓库的 URL，并在迁移或更名时更新该声明。通过 GitHub Fork 产生的仓库、个人镜像、第三方再分发版本，以及任何未被 DCT 如此指定的仓库，均不属于本条款所称的“原版 Corn 项目”，其使用仅受根目录 LICENSE（MIT）约束。

1. 适用范围：本条款仅约束“向原版 Corn 项目贡献代码／文档”的行为。
   对于有开发者在任意一个非 Corn 项目中使用 Corn 项目源码或文档的行为，不受本贡献许可条款处置；该等外部使用一律仅受根目录 LICENSE 中的 MIT 使用许可条款约束。

2. 代码著作权归属：贡献者就其提交到原版 Corn 项目的每一段代码，保留该段代码的原始著作权（Copyright）。争议发生时，可以调用 Git 提交记录或 GitHub Pull Request 记录作为证据或依据。对于贡献中由生成式人工智能生成内容的部分，其著作权归属不适用本条规定，应依据第 5 条处理。

3. 贡献许可授权：贡献者在此不可撤销、永久、免版税地向 DCT 授予一项非独占权利，允许 DCT 在原版 Corn 项目中复制、修改、分发该贡献，并依据 MIT 许可证条款授予许可，使 DCT 能够以项目整体名义维护、发布、授权 Corn 及其后续版本。DCT 不得利用本条款将该贡献用于 MIT 许可证之外的任何闭源或商业授权发布。

   贡献者提交（GitHub Pull Request / Git commit）即视为接受本条款。

4. 产品级权利归属：原版 Corn 项目的整体著作权，以及以 DCT 名义对外发布的产品的著作权与商标权利，归 Deplayer Creator Team 所有。此项规定不影响贡献者依据第 2 条对其所提交代码保留的原始著作权。
